# 《哪吒不会飞》游戏设计文档（GDD）

- 文档版本：V1.0
- 产品阶段：第一版 / MVP
- 游戏类型：单指操作、无限飞行、分数挑战
- 目标平台：微信小游戏
- 屏幕方向：竖屏

## 1. 产品愿景

用最少的操作创造清晰、紧张又带喜剧感的飞行体验。玩家无需学习复杂规则，只需点击屏幕，就能理解“让哪吒别掉下去，并穿过障碍”的目标。

游戏的识别点不是复刻经典管道，而是：一个还没有熟练掌握风火轮的小哪吒，在温暖、充满生命力的陈塘关上空跌跌撞撞地飞行。

## 2. 目标体验

- 3 秒内理解操作。
- 10 秒内经历第一次得分或失败。
- 失败原因清晰，玩家愿意立刻再来一次。
- 随着分数提高，紧张感逐渐增加，但不出现不可通过的随机组合。
- 画面轻松、明亮、可爱，失败表现偏喜剧而非挫败。

## 3. 核心循环

进入游戏 → 待机 → 点击起飞 → 穿越障碍 → 获得分数 → 难度缓慢提高 → 碰撞失败 → 查看本局与最高分 → 重新开始。

## 4. 操作规则

- 点击屏幕任意非 UI 区域：给哪吒一次向上的速度。
- 松开或不操作：哪吒受重力持续下坠。
- 连续点击：可以连续修正高度，但速度存在上限。
- 首次点击：从待机状态进入游戏状态。
- 暂停状态和结算状态下，点击不会触发飞行动作。

V1 不加入长按蓄力、左右移动、技能、冲刺或攻击。

## 5. 角色表现

### 5.1 待机

哪吒在屏幕左侧偏中位置轻微上下浮动；眨眼、呼吸，发带摆动，风火轮稳定旋转并偶尔冒出火星。

### 5.2 上升

点击后身体轻微抬头，风火轮瞬间增亮，火焰拖尾变长，并播放短促的点火声。

### 5.3 下坠

随着下降速度增加，身体逐渐向下倾斜，表情变得慌张，风火轮火焰变弱。

### 5.4 受击与失败

受击后立即停止计分和输入；短暂播放发懵或后仰动作，随后进入结算。失败表现不使用血液、伤口或沉重死亡表现。

## 6. 障碍物

每组障碍由一个上方障碍和一个下方障碍组成，中间留出安全通道。

### 6.1 下方障碍

| 障碍 | 类型 | V1 表现 | 碰撞规则 |
|---|---|---|---|
| 山峰 | 静态 | 山石、苔藓、小树和云雾 | 固定碰撞体 |
| 石柱 | 静态 | 风化裂纹、云纹、褪色符文 | 固定碰撞体 |
| 火球 | 动态障碍 | 小幅正弦浮动、旋转、火焰呼吸 | 圆形碰撞体与主体同步浮动 |

### 6.2 上方障碍

| 障碍 | 类型 | V1 表现 | 碰撞规则 |
|---|---|---|---|
| 乌云 | 动态视觉 | 云层翻滚、少量雨滴 | 固定碰撞体 |
| 雷电 | 动态障碍 | 云内先发亮，随后短暂生效并进入冷却 | 仅生效期启用固定矩形碰撞体 |
| 八卦阵 | 动态视觉 | 内外圈反向缓慢旋转 | 固定圆形碰撞体 |

### 6.3 组合

上下障碍独立选择，形成 3 × 3 共 9 种基础组合。生成器需避免同一组合连续出现三次，并必须先确定合法通道，再摆放障碍物。

## 7. 场景：陈塘关

V1 仅制作白天晴空场景，采用五层视差：

1. 天空和大云团。
2. 远山、海面和飞鸟。
3. 城墙、城楼、民居和旗帜。
4. 哪吒与障碍物游戏层。
5. 偶尔掠过的树叶、屋檐边缘和薄云前景。

玩法区域中央降低背景细节和对比度，防止建筑、云朵或装饰被误认为障碍物。

## 8. 分数与难度

- 每完整穿过一组障碍物，分数 +1。
- 穿过同一组障碍物只能计分一次。
- 本地保存历史最高分。
- 难度只通过滚动速度、通道高度和通道中心变化幅度逐步提高。
- V1 不根据障碍物种类给予不同分数。

详细参数见《数值与障碍生成规则》。

## 9. 游戏状态

| 状态 | 描述 | 允许输入 |
|---|---|---|
| Boot | 加载资源和配置 | 无 |
| Ready | 哪吒待机，展示点击提示 | 首次点击开始 |
| Playing | 正常飞行、生成障碍、计分 | 点击上升、暂停 |
| Paused | 游戏冻结 | 继续、返回主页 |
| GameOver | 结算与最高分展示 | 重新开始、返回主页 |

## 10. 界面

### 10.1 首页 / 待机

- 游戏标题《哪吒不会飞》
- “点击起飞”提示
- 音效开关
- 最高分

### 10.2 游戏中

- 当前分数
- 暂停按钮

### 10.3 暂停

- 继续游戏
- 重新开始
- 返回主页
- 音效开关

### 10.4 结算

- 本局分数
- 历史最高分
- 新纪录标识
- 重新开始
- 返回主页

## 11. 音频

- 背景音乐：竹笛、木琴、轻打击乐与自然环境声。
- 点击起飞：短促点火与掠风声。
- 得分：轻快、清晰的小铃或木质敲击声。
- 碰撞：偏喜剧的闷响。
- UI：纸张、木牌或轻敲质感。

音乐和音效支持统一开关，并保存玩家设置。

## 12. V1 明确不做

- 角色皮肤、养成和货币。
- 登录、好友榜、云存档。
- 广告、复活和付费。
- 剧情关卡、Boss、攻击技能。
- 会追踪、射击、随机变轨或临时挤压安全通道的复杂动态障碍。
- 黄昏、雨天、夜间等额外主题。
- 每日任务、成就和活动。

## 13. 成功标准

- 新玩家无需文字教程即可理解操作。
- 连续游玩 20 局不出现无解障碍。
- 碰撞结果与视觉认知一致。
- 重新开始流程快速，无多余加载。
- 主流微信小游戏目标设备上保持稳定帧率。
