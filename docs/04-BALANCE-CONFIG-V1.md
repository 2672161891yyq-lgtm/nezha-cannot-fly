# 《哪吒不会飞》数值与障碍生成规则

- 文档版本：V1.0
- 单位：设计分辨率像素、秒
- 说明：以下为首轮可玩原型基准，必须通过真机测试调整。

## 1. 基础空间

| 参数 | 初始值 | 说明 |
|---|---:|---|
| 设计宽度 | 750 | 竖屏逻辑宽度 |
| 设计高度 | 1334 | 竖屏逻辑高度 |
| 玩家 X | 220 | 从左侧计算 |
| 玩家视觉直径 | 110–130 | 含主体，不含长拖尾 |
| 玩家碰撞直径 | 78–92 | 约为视觉主体 75%–85% |
| 地面保留区 | 130 | 不进入障碍通道计算 |
| 顶部 UI 保留区 | 110 | 避免通道贴近分数和系统区 |

## 2. 玩家运动初值

| 参数 | 初始值 | 可调范围 |
|---|---:|---:|
| 重力 | -1700 | -1500 至 -1950 |
| 点击后竖直速度 | 620 | 560 至 690 |
| 最大上升速度 | 680 | 620 至 740 |
| 最大下落速度 | -850 | -760 至 -980 |
| 上升最大倾角 | 20° | 15° 至 25° |
| 下坠最大倾角 | -75° | -65° 至 -85° |

点击时建议直接设置上升速度，而不是无限叠加冲量。这样连续点击更可控，也能防止角色瞬间冲出屏幕。

## 3. 障碍初值

| 参数 | 初始值 | 可调范围 |
|---|---:|---:|
| 初始滚动速度 | 210 | 190 至 230 |
| 最大滚动速度 | 285 | 260 至 310 |
| 首个障碍距离 | 830 | 760 至 950 |
| 障碍组水平间距 | 430 | 390 至 480 |
| 初始通道高度 | 400 | 380 至 430 |
| 最小通道高度 | 330 | 315 至 350 |
| 通道中心最小 Y | 390 | 按安全区校正 |
| 通道中心最大 Y | 930 | 按安全区校正 |
| 初始中心高度差上限 | 170 | 150 至 200 |
| 后期中心高度差上限 | 220 | 190 至 240 |

障碍宽度的视觉变化不能显著改变穿越时机。若资源宽度差异较大，生成器应按障碍实际宽度修正水平间距。

## 4. 难度曲线

| 分数 | 滚动速度 | 通道高度 | 中心高度差上限 | 目标体验 |
|---:|---:|---:|---:|---|
| 0–4 | 205 | 410 | 150 | 熟悉操作 |
| 5–9 | 220 | 390 | 170 | 稳定节奏 |
| 10–19 | 240 | 370 | 190 | 需要提前判断 |
| 20–29 | 260 | 350 | 210 | 明显紧张 |
| 30+ | 280 | 335 | 220 | 高分挑战 |

数值跨区间时使用平滑插值，不能在达到某一分数后突然改变速度或通道高度。

## 5. 障碍选择权重

V1 默认等权：

- 下方：山峰 1、石柱 1、火球 1。
- 上方：乌云 1、雷电 1、八卦阵 1。

约束：

- 同一上下组合最多连续出现 2 次。
- 同一障碍类型最多连续出现 3 次。
- 前 3 组不连续出现两个视觉最抢眼的动态组合。
- 任何权重调整都不能绕过合法通道校验。

## 6. 合法通道生成算法

1. 读取当前分数对应的速度、通道高度和高度差上限。
2. 根据屏幕安全区域与动态障碍最大位移计算通道中心的合法最小值和最大值。
3. 第一组通道中心固定为画面纵向中心（Y = 0），作为新手起飞基准。
4. 从第二组开始，以“上一组通道中心 ± 高度差上限”为候选区间。
5. 将候选区间与屏幕合法区间求交集。
6. 在交集内随机选择通道中心。
7. 随机选择上下障碍类型，并执行连续重复限制。
8. 根据障碍视觉边缘放置上下节点，使其不侵入通道。
9. 校验碰撞体边缘与通道之间的最小安全余量。
10. 校验失败时最多重试 5 次；仍失败则使用上次中心附近的安全组合。

## 7. 碰撞宽容

- 玩家碰撞体不包含发带、火焰拖尾和外扩特效。
- 障碍碰撞体不包含光晕、烟雾、雨滴和火星。
- 推荐在视觉实体内缩 8%–15%。
- 旋转中的八卦阵使用固定圆形碰撞体。
- 火球碰撞核心与主体同步浮动，最大位移必须在通道生成时预留。
- 雷电预警期无伤害，生效期使用固定矩形碰撞体；预警、生效和冷却时长不得随机突变。
- 若玩家认为“没有碰到却死亡”，优先缩小碰撞体，而不是修改美术解释。

## 8. 计分判定

- 每组障碍拥有唯一运行时 ID。
- 计分线通过玩家固定 X 坐标且该组尚未计分时，分数 +1。
- 玩家同帧碰撞与穿越计分线时，优先结算碰撞，不增加分数。
- 回收障碍组时必须重置已计分标记。

## 9. 手感测试记录项

每轮测试至少记录：

- 测试设备与平均帧率。
- 前 10 局平均分、最高分。
- 首次失败发生在哪一组障碍。
- 连续点击是否容易冲顶。
- 松手后下坠是否过快。
- 玩家是否误判角色或障碍碰撞范围。
- 是否出现来不及调整的通道高度变化。
- 哪一种组合最容易造成视觉干扰。

单次测试只调整一至两个核心参数，防止无法判断变化来源。
