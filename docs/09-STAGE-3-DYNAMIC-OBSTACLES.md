## 1. 本阶段范围

阶段 3 在阶段 2 的固定对象池、九种组合与合法通道生成器上增加可预测的动态表现。

- 火球做固定周期的正弦浮动与旋转，视觉中心和圆形碰撞中心使用同一运动快照。
- 雷电按“预警 → 生效 → 冷却”循环，只有生效阶段开启伤害判定。
- 八卦阵内外圈反向旋转，继续使用固定圆形碰撞体。
- 风火轮按待机、上升、巡航和下坠四种状态改变转速与火焰长度。
- 对象池复用时重置动画相位、雷电阶段、障碍类型和计分状态。
- 关闭装饰旋转时，火球碰撞运动和雷电判定时间轴仍保持可复现。

## 2. 动态规则

| 对象 | 规则 | 碰撞规则 |
|---|---|---|
| 火球 | 振幅 18，周期 1.8 秒，旋转 280°/秒 | 半径 46 的圆形碰撞体与视觉同步浮动 |
| 雷电 | 预警 0.8 秒，生效 0.35 秒，冷却 0.65 秒 | 预警与冷却无伤害，仅生效期启用固定矩形碰撞 |
| 八卦阵 | 外圈 45°/秒，内圈 -75°/秒 | 半径 50 的圆形碰撞体固定不旋转 |
| 风火轮 | 待机、上升、巡航、下坠四档转速与火焰强度 | 不纳入哪吒碰撞范围 |

所有时间轴按 `deltaTime` 累积并可由障碍序号确定初始相位，因此同一种子下可以稳定复现。

## 3. 公平性处理

- 通道生成上下边界额外预留 18 像素动态位移空间。
- 火球基础位置同时预留碰撞半径、安全余量与最大上浮量；达到最高点时也不会侵入合法通道。
- 雷电在伤害生效前至少提供 0.8 秒明确预警，并使用文字、颜色和亮度区分三个阶段。
- 八卦阵采用圆形碰撞，避免旋转图案造成碰撞范围忽大忽小。
- 玩家、火焰拖尾、光晕和调试文字均不参与额外碰撞。

## 4. 代码职责

- `ObstacleSystemConfig.ts`：动态位移、半径、周期、阶段时长和旋转速度参数。
- `DynamicObstacleMotion.ts`：火球、雷电和八卦阵的确定性运动快照。
- `PlayerVisualDynamics.ts`：风火轮四种飞行状态与视觉参数。
- `ObstacleGenerator.ts`：将最大动态位移并入合法通道边界。
- `CollisionMath.ts`：圆形碰撞判定。
- `GrayboxGame.ts`：动态节点显示、碰撞同步、对象池重置和状态集成。
