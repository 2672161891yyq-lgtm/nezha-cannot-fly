## 1. 本阶段范围

本阶段只验证 Flappy Bird 式核心手感和单局最小闭环，不接入正式哪吒、陈塘关、障碍物和特效素材。

- 临时灰盒角色与风火轮标记。
- 点击屏幕或按空格键获得一次固定上升速度。
- 无输入时受重力持续下落。
- 上升、下落速度限制和随速度变化的角色倾斜。
- 顶部、底部安全边界。
- 一组固定灰盒障碍、向左滚动、循环复用、碰撞和计分。
- `Ready → Playing → GameOver → Ready` 状态闭环。
- 失败后点击即可重置运行状态，不重新加载场景资源。

说明：操作规则以现有 GDD 为准，是“点击上升”，不是“长按持续上升”。

## 2. 操作方式

- Ready：点击屏幕或按空格键，开始游戏并立即上升。
- Playing：每次点击或空格键都把竖直速度设置为固定值。
- GameOver：碰撞后等待 0.3 秒，点击一次回到 Ready；再点击一次开始新局。

## 3. 核心参数

参数集中在 `assets/scripts/gameplay/GrayboxConfig.ts`，后续手感调整不得在控制器中散落硬编码。

| 参数 | 当前值 |
|---|---:|
| 重力 | -1700 |
| 点击后竖直速度 | 620 |
| 最大上升速度 | 680 |
| 最大下落速度 | -850 |
| 上升最大倾角 | 20° |
| 下落最大倾角 | -75° |
| 初始滚动速度 | 210 |
| 灰盒通道高度 | 400 |
| 玩家碰撞半径 | 43 |

## 4. 代码职责

- `GrayboxConfig.ts`：阶段 1 的集中参数。
- `PlayerMotion.ts`：纯运动模型，负责重力、速度限制、点击速度和姿态插值。
- `CollisionMath.ts`：无引擎依赖的圆形与矩形碰撞计算。
- `GrayboxGame.ts`：Cocos 生命周期、输入、状态切换、计分、障碍复用和灰盒显示。
- `Boot.scene`：挂载 `GrayboxGame`，继续作为当前唯一启动场景。
