# 《哪吒不会飞》美术与音频规范

- 文档版本：V1.0
- 风格定位：东方神话 × 温暖手绘动画电影感 × 轻喜剧冒险

## 1. 风格原则

- 使用温暖、明亮、具有自然生命力的手绘视觉语言。
- 参考图用于提炼橙蓝对比、儿童化角色、东方建筑和强烈动势，不做一比一复刻。
- 不在对外素材中以具体导演或工作室的名称宣传风格。
- 哪吒采用传统神话要素上的原创设计，不能照搬现有影视、动画或游戏造型。
- 画面服务于玩法，障碍识别优先于装饰细节。

## 2. 角色规范

### 造型

- 约三头身，头部和表情适当夸张。
- 双丸子头、红色发带、朱砂色服装、赤足和双风火轮。
- 服饰纹样、护具、发型细节和风火轮结构必须原创。
- 发带和火焰不能伸入远离角色主体的位置，避免误导碰撞范围。

### 动画清单

| 动画 | 建议时长 | 循环 | 说明 |
|---|---:|---|---|
| idle | 1.5–2.0 秒 | 是 | 呼吸、悬浮、眨眼、发带摆动 |
| flap | 0.20–0.30 秒 | 否 | 抬头、收腿、风火轮爆发 |
| fall | 0.6–1.0 秒 | 是 | 慌张、发带上扬、弱火苗 |
| hit | 0.35–0.50 秒 | 否 | 后仰或短暂发懵 |
| result | 1.0–1.5 秒 | 是 | 不服气或尴尬的失败循环 |

角色逐帧动画建议使用约 12 FPS 的手绘节奏；游戏逻辑和节点移动仍按实时帧率运行。

## 3. 风火轮规范

- 左右风火轮分别旋转，存在轻微相位差。
- 火焰形状不规则，避免规则圆环和写实爆炸。
- 待机：稳定小火焰与偶发火星。
- 上升：中心变亮、火焰拉长、产生短拖尾。
- 下坠：火焰收缩、轻微抖动或冒烟。
- 火焰是全画面最醒目的暖色，但不得遮挡角色面部和通道边界。

## 4. 场景规范

### 五层视差

| 层级 | 内容 | 相对滚动速度 |
|---|---|---:|
| 天空层 | 晴空、大云团、日光 | 0.05–0.10 |
| 远景层 | 海面、淡山、飞鸟 | 0.15–0.25 |
| 陈塘关层 | 城墙、城楼、屋顶、旗帜 | 0.35–0.50 |
| 玩法层 | 角色、障碍、特效 | 1.00 |
| 前景层 | 叶片、屋檐、薄云 | 1.10–1.30 |

相对滚动速度以玩法层为 1.00。前景装饰应低频出现，不能遮挡角色或安全通道。

### 构图

- 中央玩法通道保持低细节、低对比度。
- 高细节建筑集中在背景边缘和远景。
- 远景使用偏灰、偏蓝色调；障碍物轮廓更深。
- V1 只制作白天晴空版本。

## 5. 障碍物规范

### 山峰

灰绿岩石、苔藓、小树和薄雾。轮廓清楚但不过度锋利。静态碰撞。

### 石柱

暖灰石材，带风化裂纹、原创云纹和褪色符文。静态碰撞。

### 火球

设计成圆润的火灵或旋涡火团。主体做小幅、可预测的上下浮动；碰撞核心与主体中心同步移动，火星和光晕不参与碰撞。

### 乌云

使用灰蓝、灰紫而非纯黑；云边柔软翻滚。雨滴只做装饰，不参与碰撞。

### 雷电

使用暖白或浅金色闪电。先由云层内部发亮并显示预警范围，再进入短暂生效，最后冷却；只有生效阶段具有伤害判定。

### 八卦阵

使用旧木、温润石材或青铜质感。内外圈反向旋转，符文微亮；使用稳定圆形碰撞体。

## 6. 可读性与碰撞一致性

- 碰撞体建议覆盖视觉实体的 75%–85%，给玩家少量宽容。
- 半透明光晕、烟雾、火星、雨滴和拖尾不计入碰撞。
- 玩家碰撞体不能包含发带末端和外扩火焰。
- 障碍贴图即使缩放，也必须使用经过验证的碰撞模板。
- 所有素材需提供碰撞体预览图供验收。

| 用途 | 色值 |

| 云层暖白 | `#F8EFD8` |

色值用于统一方向，不要求每个像素严格锁死。背景整体饱和度低于角色和障碍。

## 8. UI 规范

- 标题允许使用有动势的原创毛笔字。
- 正文与数字必须优先保证小屏清晰度。
- 按钮采用木牌、布旗、浅色卷轴或手绘纸片语言。
- 游戏过程中只保留当前分数和暂停按钮。
- 不使用大量宝石、金属边框、强发光和复杂渐变。
- 交互状态至少包括普通、按下、禁用。

## 9. 素材交付规范

- 源文件必须保留可编辑图层。
- 运行资源使用透明 PNG 或引擎验证支持的压缩格式。
- 命名使用小写英文与下划线，例如 `obstacle_mountain_01`。
- 角色、风火轮、发带和特效按动画需要拆层。
- 单张纹理原则上不超过 2048 × 2048。
- 图集边缘保留足够 Padding，避免缩放时串色。
- 每项资源同时记录原始尺寸、锚点、缩放基准和碰撞体建议。

## 10. V1 美术资源清单

- 哪吒：idle、flap、fall、hit、result。
- 风火轮：常态、加速、弱火、火星、拖尾。
- 障碍：山峰、石柱、火球、乌云、雷电、八卦阵各 1 套。
- 背景：五层循环素材。
- UI：首页、分数、暂停、结算、按钮、点击提示、新纪录。
- 特效：得分、碰撞、火星、薄云、叶片。
- 图标：游戏图标、音效开关、暂停。

## 11. 音频清单

| 类型 | 数量建议 | 说明 |
|---|---:|---|
| 背景音乐 | 1 | 可无缝循环，轻快但不急促 |
| 点击起飞 | 2–3 个变体 | 随机播放，避免机械重复 |
| 得分 | 1–2 个变体 | 清脆、短促 |
| 碰撞 | 1–2 个变体 | 喜剧化闷响 |
| UI 点击 | 1 | 轻木质或纸张感 |
| 风与环境 | 1 | 低音量循环 |

音频交付前需要做循环点、峰值和响度统一，避免频繁点击时爆音。
